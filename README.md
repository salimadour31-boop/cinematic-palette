# Cinematic Palette

Outil gratuit et open source pour générer des palettes de couleurs cinématiques.

**Démo :** https://salimadour31-boop.github.io/cinematic-palette/

## Description

Générateur de palettes inspiré des looks de films (noir, sci-fi, western, romance...). Choisissez un genre, une ambiance, et obtenez des couleurs harmonieuses avec codes HEX. Export PNG, copie CSS. Tout dans le navigateur, aucune installation.

## Usage

1. Ouvrez la démo ou clonez le dépôt.
2. Sélectionnez un genre ou une ambiance.
3. Cliquez sur Générer.
4. Copiez les codes HEX ou exportez la palette.

## Fonctionnalités

- Palettes prédéfinies par genre cinématique
- Génération aléatoire harmonieuse
- Multilingue (FR / EN)
- Responsive
- Export PNG simple
- Aucune dépendance externe
